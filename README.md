# Fern & Field Garden Co. — Best package sample

A sample website built by **Pontavia Consulting** to show what the **Best (from $3,100)** website package includes.
Fern & Field Garden Co. is a made-up business in Ocala, Florida.

Live demo: https://pontavia-consulting.github.io/Pontavia-Sample-Best/
Compare all three packages: https://pontavia-consulting.github.io/Pontavia-Samples/

A full online store and customer experience on top of everything in Better: shoppers can find, filter, buy and pick up plants, buy workshop tickets, earn rewards and get answers from a chat widget, with integrations to the point of sale.

## What's included

- Everything in Better
- Online store: 16 products, filters, search, sort, stock counts, wishlist
- Cart drawer with free-delivery progress bar, and a full checkout with pickup times or delivery
- Delivery ZIP checker for Marion County
- Workshop tickets go into the same cart
- Customer account with rewards points, order history, saved plants and care reminders
- Plant finder quiz with scored recommendations
- Site-wide instant search
- Chat widget with quick answers
- Integration touchpoints: payments (Square), live stock from the register, text-when-ready notifications
- Interactive month-by-month planting calendar on the home page

## Pages

- `index.html — home with interactive planting calendar`
- `shop.html — store with filters, search and sort`
- `product.html — product details (?id=)`
- `cart.html — cart`
- `checkout.html — pickup or delivery checkout`
- `account.html — orders, saved plants, rewards, care reminders`
- `finder.html — plant finder quiz`
- `services.html, design.html, gallery.html, workshops.html, team.html, journal.html, faq.html, contact.html — as in Better`

## Notes

- Plain HTML, CSS and JavaScript. No build step, no framework, nothing to install.
- All plant pictures are SVG illustrations drawn by `assets/art.js`, so there are no stock photos to license.
- This is a front-end demo only: forms, bookings, the cart and checkout work in the browser but don't send or store anything on a server.
- To preview locally, open `index.html` in a browser, or run `python3 -m http.server` in this folder.
